# 실제 영화 수정 검증 — 2026-10-09

## 수정한 내용

- 편집 소스를 H.264/PCM MOV로 생성하는 옵션과 기본값을 추가했다. 기존 MP4/AAC도 선택 가능하다.
- 중앙 크롭 대신 fit_blur를 기본값으로 사용한다. 가로 화면 전체를 중앙에 보존하고 배경을 확대·흐림 처리한다. 자동 얼굴 추적은 아니다.
- 컷별 3프레임에서 공통 검은 띠만 보수적으로 제거한다. 초반 2컷 위아래 각136픽셀, 중·후반 7컷 각16픽셀을 제거했다. 안전 여백을 남기므로 경계에 소량의 검은 픽셀이 남을 수 있다. 판별이 모호하면 제거하지 않는다.
- Premiere PCM 마스터를 최종 H.264/AAC로 변환하는 export_delivery.py를 추가했다. 강제로 오디오를 앞당기는 보정은 사용하지 않는다.

## 실제 검증

사용자 영화의 600.6초·3603.6초·6606.6초 위치에서 각20.02초를 추출한 동일 샘플을 다시 처리했다. 9컷, 1407프레임, 23.976fps, 1080×1920. 원본 영화는 변경하지 않았다.

| 경로 | 편집 소스 대비 오디오 시간 차이 |
|---|---|
| PCM MOV → Premiere H.264/AAC 직접 출력 | 약21.375ms 지연 잔존 |
| PCM MOV → Premiere ProRes/PCM 마스터 | 표본 18개 모두0ms |
| 위 마스터 → export_delivery.py → 최종 MP4 | 표본 18개 모두0ms |

측정: 9컷 각각0.1초 지점에서0.8초 구간, 좌우 채널별8kHz 파형 상관, ±200ms 탐색, 0.125ms 간격. 0ms는 이 측정 해상도 내 결과다. 일부 구간 상관계수는 약0.79~0.92, 나머지는0.99 이상이므로 파형의 완전한 비트 일치를 주장하지 않는다.

최종 MP4 영상1407프레임/58.683625초, 오디오58.683000초. 마지막 길이 차이는0.625ms이며 전체 디코딩 오류 없음. 모든 구간의 입 모양을 사람처럼 시청하여 평가한 것은 아니다. 전편 누적 오차 검증도 아니다.

첫 컷의 기존 중앙 크롭에서 잘렸던 오른쪽 인물이 수정 화면에서는 가로 화면 안에 보존되는 것을 Premiere 미리보기 및 실제 생성 이미지로 확인했다.

자동 테스트13개 통과. PCM 코덱, 가장자리 색상 표식을 보존하는 화면 배치, 검은 띠 제거, MP4 변환 후 파형 정렬, 덮어쓰기 방지 및 기존 취소·배치·XML 테스트를 포함한다.

## 파일

- Movie_Fixed.xml: 수정된9개 MOV를 사용하는 XML. 시퀀스명 Movie_Fixed_PCM_Fit.
- results.json: 설정, 컷별 제거 영역, 미디어 경로.
- premiere-export-check.json: 직접 AAC 출력 지연 재현 기록.
- master-check.json / final-export-check.json: 개선된 출력 경로 측정 기록.
- 상위 outputs/Movie_Fixed_Master.mov: Premiere가 실제 출력한 ProRes/PCM 마스터.
- 상위 outputs/Movie_Fixed_Final.mp4: 최종 확인용 MP4.
- 상위 outputs/Movie_Fixed_PCM_Fit.prproj: 수정 시퀀스가 열린 검수 프로젝트. 이전 비교 시퀀스도 남아 있으므로 수정 시퀀스 이름을 확인한다.

배포 모듈 ZIP에는 이 영화 파일을 넣지 않았다. 검은 띠 검출은 휴리스틱이므로 어두운 장면·화면비가 변하는 컷·자막이 있는 컷은 확인해야 한다. 인물 중심으로 화면을 가득 채우는 자동 재구도 기능은 포함하지 않는다.
