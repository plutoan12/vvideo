# 더 킬러스 — 나레이션 포함 60초 샘플

완성 영상: The_Killers_60s_Narrated.mp4 (1080×1920, 24000/1001 fps, 1440프레임, 60.06초).
Mac의 한국어 합성음성 Yuna로 제작했습니다. 사람의 녹음 또는 특정 성우의 복제 음성이 아닙니다.
기존 3개 구간에서 만든 샘플 몽타주에 결말을 밝히지 않는 작품 소개를 넣었습니다. 영화 전체 줄거리와 장면을 문장별로 대응시킨 완성 리뷰는 아닙니다.

## 편집

Premiere에서 Narrated_Editable.xml을 가져오면 The_Killers_Narrated_60s 시퀀스가 열립니다. 실제 Premiere 가져오기와 60초 시퀀스 표시를 확인했습니다.
V1은 영상, A1/A2는 낮춘 영화 원음의 좌우 채널, A3/A4는 나레이션의 좌우 채널입니다.
상위 outputs 폴더의 The_Killers_Narrated.prproj에도 저장했습니다. 이 프로젝트에는 이전 검수 시퀀스도 포함됩니다. 새 프로젝트에서 작업하려면 XML을 가져오세요.
XML과 미디어 파일은 함께 보관하세요. 경로가 바뀌면 미디어를 다시 연결해야 합니다.

Narration_KO.wav는 타임라인 0초에 놓는 음성 파일입니다. 실제 말은 0.65초에 시작하고 약 57.86초에 끝납니다.
Narration_Paragraphs.srt는 6개 문단 단위 참고 자막이며 영상에 입혀져 있지 않습니다.
원음은 음성이 나올 때 더 낮아지도록 처리했습니다. 별도 음악은 추가하지 않았습니다.

## 검증 범위

최종 MP4 전체 디코딩, 프레임 수, 영상·음성 길이, 6개 나레이션 구간의 파형 대응을 검사했습니다. 결과는 verification.json에 있습니다.
사람이 전 구간을 청취한 품질 검수 또는 전체 영화의 싱크 검증을 뜻하지 않습니다.
