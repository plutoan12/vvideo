# 추가 검수 — 2026-10-08

## 발견 및 수정

좌440Hz/우880Hz 합성 스테레오 소스를 사용했다. 렌더된 개별 MP4는 정상이었으나, 기존 XML을 Premiere에서 가져와 내보내면 두 채널에 양쪽 신호가 섞였다. XML의 A1/A2 clipitem에 audiopan -1/+1을 추가했다. 수정 XML을 다시 가져오고 Premiere H.264/AAC로 내보내어 수정 효과를 확인했다.

| 검사 | 실제 측정 결과 |
|---|---|
| 시퀀스/출력 크기 | 1080×1920 |
| 프레임레이트 | 30000/1001 (29.97) |
| 총 영상 프레임 | 180 |
| 영상/오디오 길이 | 모두 6.006000초 |
| 컷 경계 | 0부터 센 90번 프레임에서 빨강→초록 |
| 빈 검정 프레임 | 0 |
| 오디오 | 48kHz, 2채널 |
| 첫 컷/둘째 컷 FFT | 모두 L440Hz / R880Hz |
| 반대쪽 테스트 주파수 성분 | 해당 주파수 대비 -95.3dB 이하 |
| 자동 테스트 | 11개 통과 (실제 FFmpeg 미디어 검사 포함) |

수정 시퀀스: Stereo_Fixed_2997. 실제 출력은 상위 outputs의 Shorts_NTSC_Stereo_Fixed.mp4, 저장 프로젝트는 Shorts_XML_StereoFixed.prproj. 해당 프로젝트에는 비교용 이전 시퀀스도 있으므로 수정 시퀀스 이름을 확인해야 한다. 이전 LinkImport 시퀀스의 누락 파일 알림이 나올 수 있다.

영상 전체 디코딩과 프레임 색상 검사, 각 컷 중간 1초 구간의 음성 FFT로 검증했다. 이는 합성 샘플 검증이며 실제 영화의 입 모양/대사 싱크, 장편 누적 오차, HDR/VFR, 외부 내레이션 정렬을 보증하지 않는다. VideoComeOn Local 실제 저장소 통합은 아직 수행하지 않았다.

이전 VERIFICATION.md의 좌우 라벨/미터 확인만으로는 실제 채널 분리를 보장할 수 없었다. 이번 출력 측정이 그 확인을 보완한다. 이전에 가져온 XML 시퀀스는 코드만 교체해도 자동 수정되지 않으므로 수정 XML을 다시 가져와야 한다.
