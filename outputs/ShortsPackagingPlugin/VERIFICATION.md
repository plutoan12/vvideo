VideoComeOn Local 실제 저장소에 연결한 테스트는 수행하지 못했습니다. 실제 장편 영화, HDR/VFR, 인물 중심 크롭과 내레이션·자막 제작은 검증 범위 밖입니다. 이전 YouTube 샘플 파일은 현 경로에 없어 이번 검증에는 합성 테스트 영상을 사용했습니다.

## FCP XML 기능 추가 검증

기존 9개 미디어 테스트와 XML 전용 2개 테스트, 총 11개 통과.
XML 전용 검사: NTSC 분수 fps, 한글·공백·& 경로 인코딩, 무음 클립을 사이에 둔 영상/오디오 링크 인덱스, 빈틈없는 영상 시작·끝, 총 길이, 기존 XML 덮어쓰기 방지, 빈 목록과 잘못된 fps 거부.

실제 2초·0.5초·2초 테스트 영상을 24fps 1080×1920으로 처리하여 0.5초 컷을 제외하고, 48프레임 클립 2개와 총 96프레임(4초) XML을 생성했다. Premiere 가져오기로 두 MP4와 xml-demo-input_SourceTimeline 시퀀스(24fps)가 프로젝트 패널에 생성된 것을 화면에서 확인했다.

초기 창 제어 오류를 세션 재연결로 해결했고, 아래 추가 검증을 완료했다. 가져오기 과정의 미디어 누락 대화상자는 기존 LinkImport_Test 프로젝트의 ready.mp4를 가리켰으며 새 scene-0001/0002.mp4를 가리키지 않았다. 기존 프로젝트 파일에는 이번 가져오기 결과를 저장하지 않았다.


### Premiere 실제 타임라인 검수 완료

- xml-demo-input_SourceTimeline을 실제 편집 타임라인에서 열었다.
- V1에 scene-0001/0002 두 컷, A1(L)·A2(R)에 각 컷의 연결된 오디오가 표시된다.
- 00:00:01:23의 빨간 첫 컷에서 한 프레임 이동하면 00:00:02:00의 초록 두 번째 컷이 된다. 컷 사이 빈 프레임이 없다.
- 전체 00:00:04:00 시퀀스를 재생했고 재생 진행과 양쪽 오디오 미터 반응을 확인했다. 실제 스피커 소리를 청취해 판단한 것은 아니다.
- Shorts_XML_Validated.prproj에 별도 저장했다. 저장 프로젝트 내부에서도 영상과 양쪽 오디오의 구간이 0~508032000000 및 508032000000~1016064000000 ticks로 일치함을 확인했다.
- 검수 프로젝트에는 이전 LinkImport 테스트 시퀀스도 남아 있다. 그 시퀀스의 기존 ready.mp4는 현재 경로에 없으므로 미디어 연결 알림이 나올 수 있다. 새 XML 데모의 두 파일은 정상 연결되어 있다.
- 실제 영화 전편, NTSC 시퀀스의 Premiere 재생, 구별되는 좌우 신호의 채널 분리 정확도는 이번 합성 영상 검수 범위에 포함되지 않는다.
